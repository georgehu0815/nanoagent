## Understanding WhatsApp Identifiers

### 1. Direct Messages (Personal Chats)

**Format:** `<phone_number>@s.whatsapp.net`

**Examples:**
- Your account: `13522355298@s.whatsapp.net`
- Someone else: `14155551234@s.whatsapp.net` (if their number is +1-415-555-1234)
- International: `447700900123@s.whatsapp.net` (UK number: +44-7700-900123)

**Phone Number Format:**
- Remove all spaces, dashes, and formatting
- Include country code WITHOUT the `+`
- Examples:
  - +1 (415) 555-1234 → `14155551234`
  - +44 7700 900 123 → `447700900123`
  - +86 138 0013 8000 → `8613800138000`

### 2. Group Chats

**Format:** `<group_id>@g.us`

**Example:** `120363012345678901@g.us`

Group IDs are automatically generated by WhatsApp and look like random numbers.

## Configuring WhatsApp Access Control

### Current Configuration

Your WhatsApp channel settings (`~/.nanobot/config.json`):

```json
{
  "enabled": true,
  "bridgeUrl": "ws://localhost:3001",
  "allowFrom": []
}
```

⚠️ **Security Note:** `allowFrom` is currently **empty**, which means **ANYONE** who has your WhatsApp number can message the bot!

### Restrict Access to Specific Users

To allow only specific phone numbers:

```json
{
  "enabled": true,
  "bridgeUrl": "ws://localhost:3001",
  "allowFrom": [
    "14155551234@s.whatsapp.net",
    "447700900123@s.whatsapp.net"
  ]
}
```

**Steps:**
1. Find the phone numbers you want to allow (use Method 1 above)
2. Edit `~/.nanobot/config.json`
3. Add phone numbers in the format `<number>@s.whatsapp.net`
4. Restart the gateway: `nanobot gateway`

## Sending Messages TO WhatsApp Users

### From Code (Tools)

If you want the agent to send a message to a specific WhatsApp user:

```python
from nanobot.bus.events import OutboundMessage
from nanobot.bus.queue import MessageBus

msg = OutboundMessage(
    channel="whatsapp",
    chat_id="14155551234@s.whatsapp.net",  # Full WhatsApp ID
    content="Hello from nanobot!"
)

await bus.publish_outbound(msg)
```

### From Cron Jobs

Schedule messages to specific WhatsApp users:

```bash
nanobot cron add \
  --name "morning_reminder" \
  --schedule "0 9 * * *" \
  --channel whatsapp \
  --to "14155551234@s.whatsapp.net" \
  --message "Good morning! Here's your daily summary."
```

| **India** | `91<number>` | `919876543210@s.whatsapp.net` |
| **Germany** | `49<number>` | `491701234567@s.whatsapp.net` |
| **Brazil** | `55<number>` | `5511987654321@s.whatsapp.net` |

**Key Points:**
- Always remove the leading `+` from country code
- Remove all spaces, dashes, parentheses
- Keep only digits + `@s.whatsapp.net`

Always set `allowFrom` to specific phone numbers:

```json
{
  "allowFrom": [
    "13522355298@s.whatsapp.net"  // Only you
  ]
}
```

### 2. Monitor Unknown Senders

Run the monitoring script periodically to see who's trying to message:
```bash

```

### 3. Use Separate WhatsApp Number

Consider using a dedicated WhatsApp number for nanobot, not your personal number.

### 4. Review Session Files

Periodically check who has messaged you:
```bash
ls -la ~/.nanobot/sessions/whatsapp-*
```

### 5. Rotate Credentials

If you suspect unauthorized access:
```bash
# 1. Stop gateway
pkill -f "nanobot gateway"

# 2. Remove credentials
rm -rf ~/.nanobot/whatsapp-auth/*

# 3. Restart and re-scan QR
nanobot gateway
```
